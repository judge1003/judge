# English Buddy — 초등 3학년용 핸즈프리 화상영어

안드로이드 태블릿 Chrome에서 **버튼 없이 말로만** 대화하는 AI 영어 친구입니다.
블록 쌓기 게임 느낌의 "블록 월드", 3대3 대전 게임 느낌의 "배틀 아레나" 테마를 고를 수 있습니다.
(특정 게임의 상표·캐릭터·이미지는 쓰지 않고, 직접 그린 블록 캐릭터를 씁니다.)

## 동작 방식

```
[태블릿 Chrome (PWA)]                               [Node 서버]                 [Claude API]
 마이크 → 음성인식(en-US) → 문장 완성 감지 ──POST /api/chat──▶ 입력 검증·레이트리밋 ──▶ claude-opus-5-5
 스피커 ◀─ 음성합성(영어 + 한국어 힌트) ◀──── JSON 응답 ◀──────────────────────────── (structured output)
```

- **핸즈프리 루프**: 듣기 → 아이가 말을 끝내면 자동 전송 → 생각 → Buddy가 말하기 → 다시 듣기.
  버튼은 처음 "시작하기" 한 번뿐입니다. 브라우저 정책상 마이크·소리는 처음에 한 번 화면을 눌러야 켤 수 있습니다.
- **에코 방지**: Buddy가 말하는 동안에는 마이크를 완전히 끕니다. 그래도 자기 말이 다시 들리면 걸러냅니다.
- **잡음 필터**: "um/uh" 같은 군소리, 인식 신뢰도가 낮은 결과는 무시합니다.
- **침묵 처리**: 25초 동안 말이 없으면 Buddy가 쉬운 질문으로 말을 겁니다. 두 번 해도 반응이 없으면 마이크를 끄고 쉬는 모드로 들어갑니다.
- **Pre-A1 맞춤 응답**: 1~2문장, 15단어 이하로 말합니다. 아이가 막히거나 한국어로 말하면 💡한국어 힌트와 "이렇게 말해 봐!" 예문을 보여 주고 읽어 줍니다.
- **그림 카드**: 이미지를 생성하지 않고 이모지로 바로 보여 줍니다. 그래서 "picture pending"처럼 그림을 기다리는 일이 없습니다.
- **보상과 리포트**: 영어 문장을 말하면 ⭐를 받습니다. 📒 리포트에서 오늘 말한 문장과 새로 배운 단어를 볼 수 있습니다. 기록은 태블릿 안에만 저장됩니다.
- **카메라**: 아이 얼굴을 작은 창에 띄워 화상통화처럼 보이게 합니다. 영상은 **화면에만 표시하고 서버로 보내지 않습니다**. 설정에서 끌 수 있습니다.

## 실행

```bash
npm install
# API 키 없이 화면만 확인(가짜 응답)
npm run dev                       # http://localhost:8080
# 실제 운영
ANTHROPIC_API_KEY=sk-ant-... ACCESS_CODE=우리집코드 npm start
```

| 환경변수 | 설명 | 기본값 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키. **서버에만** 둡니다. 없으면 자동으로 가짜 응답 모드 | - |
| `ACCESS_CODE` | 가족 접속 코드. 앱의 ⚙️ 설정에 입력합니다. 주소가 새어도 남이 API를 못 씁니다 | 없음(권장: 설정) |
| `CLAUDE_MODEL` | 사용할 모델 | `claude-opus-5-5` |
| `RATE_PER_MIN` | IP당 분당 요청 수 제한 | 20 |
| `PORT` / `HOST` | 수신 포트/주소 | 8080 / 0.0.0.0 |
| `TLS_CERT` / `TLS_KEY` | 인증서 경로를 주면 HTTPS로 실행 | - |
| `MOCK=1` | 강제로 가짜 응답 모드 | - |

## 안드로이드 태블릿에 설치

1. **HTTPS 접속이 꼭 필요합니다.** Chrome은 보안 연결(https, 또는 localhost)이 아니면 마이크와 카메라를 막습니다. 방법은 셋 중 하나입니다.
   - 클라우드(Cloud Run, Fly.io, Render 등)에 배포해서 https 주소를 쓴다 (가장 간단)
   - 집 안 PC에서 `TLS_CERT`/`TLS_KEY`로 직접 HTTPS를 연다. 사설 인증서를 쓰면 태블릿에 그 인증서를 신뢰하도록 등록해야 합니다
   - Cloudflare Tunnel 같은 터널로 https 주소를 만든다
2. 태블릿 Chrome으로 접속 → 메뉴 → **홈 화면에 추가**하면 전체 화면 앱처럼 열립니다.
3. ⚙️ 설정에서 아이 이름(영문), 테마, 말하기 속도, 접속 코드를 입력합니다.
4. 처음 시작할 때 마이크·카메라 권한을 **허용**합니다.

## 보안 설계

- API 키는 서버 환경변수에만 두고 브라우저로 보내지 않습니다.
- `ACCESS_CODE` 비교는 타이밍 공격을 막는 방식(`timingSafeEqual`)으로 합니다. IP별 분당 요청 수를 제한하고, 요청 본문은 32KB까지만 받습니다.
- 대화 기록은 최근 16턴, 한 문장 300자까지만 받습니다. 역할이 user/assistant가 아니면 버립니다. 아이 이름에서 글자와 공백 외의 문자는 지웁니다(프롬프트 주입 완화).
- 응답 헤더에 CSP(`default-src 'self'`), `nosniff`, `no-referrer`, Permissions-Policy(마이크·카메라는 자기 사이트만 허용)를 넣었습니다.
- 정적 파일은 `public/` 밖으로 나갈 수 없게 막았습니다(경로 우회 테스트 포함).
- 시스템 프롬프트로 개인정보(주소·학교·전화번호)를 묻지 않게 했습니다. 아이가 다쳤다거나 무섭다고 하면 부모님께 말하라고 안내합니다.
- 모델이 응답을 거절하면 서버 측 fallback(`fallbacks: "default"`)으로 다른 모델이 이어서 답합니다. 그래도 안 되면 안전한 기본 문장으로 답합니다.

## 알려진 제약 (정직하게 적습니다)

- **음성 인식은 Chrome 내장 Web Speech API입니다.** 안드로이드 Chrome에서는 기본적으로 음성이 Google 서버로 보내져 인식됩니다(Claude 서버가 아닙니다). 개인정보 측면에서 알고 쓰셔야 합니다.
- 안드로이드는 음성 인식을 새로 시작할 때마다 짧은 "띵" 소리를 내는 기기가 있습니다. 웹 앱에서는 이 소리를 끌 수 없습니다.
- 인식 언어는 영어(en-US)로 고정했습니다. 아이가 한국어로 말하면 엉뚱한 영어 단어로 바뀔 수 있습니다. 그래서 Buddy가 "잘못 들었을 수 있다"고 가정하고 쉬운 선택 질문으로 되묻게 했습니다.
- TV 소리나 가족 대화를 완벽하게 거르지는 못합니다. 조용한 방에서, 태블릿을 아이 가까이 두고 쓰시길 권합니다.
- 카메라와 음성 인식을 동시에 켜면 일부 기기에서 충돌할 수 있습니다. 실제 기기로 확인하지 못했습니다. 문제가 생기면 설정에서 카메라를 끄세요.
